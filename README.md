# 📊 Price Analysis Dashboard | Power BI Capstone Project

## 📌 Project Overview

The **Price Analysis Dashboard** is an end-to-end Power BI project designed to analyze sales performance, product trends, discounts, and regional performance. It provides interactive visualizations and business insights to help stakeholders make data-driven decisions.

This project demonstrates skills in **Power BI, Power Query, DAX, Data Modeling, and Dashboard Design**.

---

## 🎯 Project Objectives

- Analyze overall sales performance
- Identify top-selling products
- Monitor monthly sales trends
- Compare category performance
- Evaluate discounts and pricing strategies
- Analyze city-wise and regional sales
- Track business KPIs through interactive dashboards

## 📌 Business Insights

- Laptop is the highest revenue-generating product.
- Electronics contribute the highest sales among all categories.
- North region records the highest revenue.
- September achieved the highest monthly sales.
- Discounts significantly influence customer purchasing behavior.
- Metro cities contribute the largest share of total sales.
